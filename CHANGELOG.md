# История изменений

Изменения пользовательских стилей для десктопного Bitrix24. Даты соответствуют публикациям в репозитории. Ниже описано итоговое поведение правок; отдельные технические коммиты объединены по смыслу.

## 12 ноября 2026

### Чаты проектов

- Добавлено визуальное скрытие чатов проектов из общего и компактного списков чатов.
- Отдельные чаты задач и раздел проектов сохранены.
- Добавлена версия `hide-project-chats/user_style.css`: только скрытие чатов проектов, без тёмной темы и изменения цветов.
- Скрытие не меняет участие в проекте, уведомления и общий счётчик непрочитанных. Исключение проектов из общего счётчика пока не реализовано.

### Сообщения, цитаты и вложения

- Цвет обычного текста своих сообщений приведён к цвету входящих сообщений, чтобы убрать лишнюю визуальную тяжесть белого текста.
- Удалены переопределения жирности своих сообщений. Намеренное выделение жирным сохраняется.
- Улучшен контраст цитат в уведомлениях о закреплении сообщения и текста в списке закреплённых сообщений.
- Добавлены светлые цвета для подписи «Галерея», названий файлов, количества вложений и размеров файлов в цитатах.
- Дополнены правила для файлов, отображаемых через компоненты BaseFileItem и AttachFile: они используют собственные стили имени и размера, независимо от подписи цитаты.

### Задачи

- Исправлено оформление отдельного окна «Просмотры»: цвет задаётся внутреннему фоновому слою TasksPopup, а также именам пользователей, заголовку и датам.
- Общие правила тёмной темы для плашек исключены из строк таблиц. Сроки в списке задач используют штатные цвета и состояния Битрикса.
- Сохранено штатное оформление сроков в канбане без перекрашивания самих карточек.

### Меню портала

- Добавлены тёмные фоны для блоков лицензии и интегратора в меню «Мой тариф».
- Добавлены тёмные фоны для блоков сотрудников, структуры компании и проектов в меню «Пригласить».
- Улучшен контраст заголовков, пояснений и кнопок этих меню.
- Для баннера приглашения сотрудников сохранён белый текст на бирюзовом фоне.

### Установка, обновление и документация

- README переведён на русский: описаны обе версии CSS, ручная установка, ограничения и откат.
- Добавлен необязательный обновлятор `scripts/Update-Theme.ps1` для Windows.
- После однократного запуска с `-Install` обновлятор создаёт задачу текущего пользователя: проверка при входе в Windows и раз в час во время активного сеанса.
- Поддержаны тёмная версия, версия только со скрытием проектов и явное указание пути к `user_style.css`.
- До замены сохраняются исходный файл `.original` и предыдущая версия `.previous`. При ошибке загрузки текущий CSS не заменяется; неизменившийся файл повторно не записывается.
- Добавлен параметр `-Uninstall` для отключения задачи обновления с сохранением темы и резервных копий.
- Обновлятор заменяет CSS целиком и не обновляет собственный код. Личные дополнения к CSS нужно хранить отдельно.

## 11 ноября 2026

Первая публикация адаптированной темы для обновлённых чатов и задач десктопного Bitrix24, на основе `skomaroh/bitrix24-dark-chat`.

### Поиск и пересылка

- Адаптированы фон и текст результатов поиска, недавних поисков и выбора получателя.
- Добавлены правила для поиска чатов и чатов задач.
- Доработано тёмное оформление окна пересылки: список получателей, вкладки и кнопка отправки.

### Поле сообщения и вложения

- Доработано размещение поля ввода и кнопок редактора сообщения.
- Скрыта кнопка «Панель приложений» рядом с полем ввода.
- Доработано окно отправки вложений: заголовок «Выбрано», кнопка добавления файлов и поле подписи.
- Улучшена читаемость подсказок в полях ввода.

### Чаты и меню

- Добавлены правила контраста для счётчиков непрочитанных сообщений, в том числе при наведении на чат задачи.
- Улучшена читаемость счётчиков в боковой панели чата.
- Доработаны меню профиля и окно добавления участников в чат: фон, текст, поля и кнопки.

### Формы и карточки задач

- Адаптированы форма быстрого создания задачи, поля, пояснения, кнопки и срок.
- Добавлены правила для описания задачи и его редактора.
- Доработаны отдельное меню действий задачи и редактор чек-листов, включая текст пунктов и ссылки.
- Для сроков в канбане восстановлены штатные варианты плашек Битрикса; исходное оформление карточек сохранено.

### Репозиторий

- Опубликована основная версия `default/user_style.css` и инструкция установки.
- Сохранены исходная лицензия Apache-2.0 и сведения об авторстве в LICENSE и NOTICE.

## Ограничения проверки

Селекторы сверялись с локальными исходниками `im 26.1300.0` и `tasks 26.900.0`; часть правок уточнялась по сообщениям и изображениям пользователей. Проверки синтаксиса и соответствия селекторов не заменяют визуальную проверку в работающем клиенте. Полная проверка всех экранов и версий Bitrix24 не проводилась.
